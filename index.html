3D CHARACTER INTEGRATION

WORK IN PROGRESS

Acnhoes IRL

A work-in-progress experiment in bringing a 3D character into pre-recorded real-world footage. I use Unity to create and render the character scene, with Mocha Pro for tracking and compositing.

The current clip is an early integration test, exploring how a 3D character can be placed naturally within a live-action shot. Other integration details are still being developed.

  • 3D character integration
  • Unity
  • Mocha Pro
  • Compositing

ORIGINAL CHARACTER PROJECT

WORK IN PROGRESS

Chibinvasion

An original character project in development, exploring how stylized characters could interact with the real world through short videos and compositing experiments.
